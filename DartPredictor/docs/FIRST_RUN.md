# Первый запуск DartPredictor

## Шаг 1 — Запуск приложения

Откройте DartPredictor из Launchpad или Applications.

## Шаг 2 — Онбординг

При первом запуске отображается пошаговая настройка:

1. **Введение** — описание возможностей приложения.
2. **Разрешение на запис экрана** — откройте Системные настройки и включите DartPredictor в разделе «Запись экрана».
3. **Область результатов** — выделите область экрана, где букмекер показывает последние выпавшие числа.
4. **Область игрока** — выделите область с видео игрока.
5. **Проверка OCR** — тест распознавания чисел.
6. **Тестовый результат** — проверка готовности системы.
7. **Paper Prediction** — включение безопасного режима тестирования.

## Шаг 3 — Выбор областей экрана

### Область результатов

- Перетащите мышь для выделения прямоугольной области.
- **Enter** — подтвердить, **Esc** — отмена.
- Область должна полностью покрывать числа результатов.

### Область игрока

- Выделите область, где виден игрок (корпус, руки, замах).
- Используйте минимально необходимый размер для снижения нагрузки.

## Шаг 4 — Разрешение на запис экрана

1. Системные настройки → Конфиденциальность и безопасность → Запись экрана.
2. Включите переключатель для DartPredictor.
3. Перезапустите приложение при необходимости.

## Шаг 5 — Paper Prediction

Рекомендуется начать в режиме **Paper Prediction**:

- Прогнозы отображаются, но ставки не выполняются.
- Статистика накапливается для оценки точности.
- Никаких автоматических действий на сайте букмекера.

## Шаг 6 — Запуск анализа

1. Откройте страницу с игрой в дартс.
2. В DartPredictor нажмите **Запустить**.
3. После каждого нового броска появится TOP-4 прогноз.
4. Плавающее окно показывает прогноз поверх других приложений.

## Интерпретация результатов

| Элемент | Описание |
|---------|----------|
| TOP-4 | Четыре наиболее вероятные числа с процентами |
| Уверенность | HIGH / MEDIUM / LOW — честная оценка модели |
| Точность TOP-4 | Реальный процент попаданий в TOP-4 |
| ✓ / ✗ | Результат последнего прогноза |

## Устранение проблем

### OCR не распознаёт числа

- Увеличьте область результатов.
- Убедитесь, что числа чётко видны.
- Проверьте, что выбрана правильная область.

### Приложение не захватывает экран

- Проверьте разрешение на запис экрана.
- Перезапустите приложение после выдачи разрешения.

### Низкая точность

- Нормально на старте (фаза «СБОР ДАННЫХ»).
- Точность растёт после 100+ бросков.
- Проверьте качество области игрока.
