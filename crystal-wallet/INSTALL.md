# Установка Crystal Wallet на iPhone

## Важно про iOS

**Готовый `.ipa` файл (как APK на Android) для iPhone без App Store сделать нельзя** без:
- Mac с Xcode
- платного Apple Developer аккаунта ($99/год)
- подписи приложения Apple

Поэтому для быстрой установки на iPhone подготовлена **PWA-версия** — она устанавливается через Safari и работает как отдельное приложение на экране «Домой».

---

## Способ 1: Скачать архив и открыть на iPhone

### Шаг 1 — Скачай архив

Файл: `crystal-wallet-ios-pwa.zip` (в папке `crystal-wallet/releases/`)

### Шаг 2 — Размести файлы онлайн

Распакуй архив и загрузи содержимое на любой хостинг с HTTPS, например:
- GitHub Pages
- Netlify Drop
- Vercel
- свой сервер

> PWA должна открываться по **HTTPS** (или localhost), иначе установка может не сработать.

### Шаг 3 — Установи на iPhone

1. Открой ссылку на приложение в **Safari** (не в Chrome).
2. Нажми кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выбери **«На экран Домой»**.
4. Нажми **«Добавить»**.

Готово — иконка появится на домашнем экране, приложение откроется в полноэкранном режиме.

---

## Способ 2: Нативное iOS-приложение (через Xcode)

Если есть Mac:

1. Открой `crystal-wallet/CrystalWallet.xcodeproj` в Xcode.
2. Выбери свой Apple Team в Signing.
3. Подключи iPhone по USB.
4. Нажми **Run** (⌘R).

Для установки на чужие iPhone без кабеля — только **TestFlight** или **App Store** (нужен Developer аккаунт).

---

## Что внутри архива

```
pwa/
├── index.html
├── app.js
├── styles.css
├── manifest.json
├── sw.js
└── icons/
```

Баланс хранится локально в браузере (`localStorage`) на твоём iPhone.

## Возможности

- Задать любое количество монет и кристаллов (до 9 999 999 999)
- Быстрые кнопки +1 000 / +100 000
- Пресеты в редакторе
- Сброс баланса
- Работает офлайн после первой загрузки
