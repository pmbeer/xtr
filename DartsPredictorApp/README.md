# Darts Predictor — приложение для macOS

Нативное приложение (Swift + SwiftUI), которое следит за экраном во время
live-трансляции дартса, фиксирует каждый бросок по изменению счёта и мгновенно
(~100–300 мс при 5-секундном окне ставки) показывает и проговаривает голосом
рекомендацию по следующей ставке: чет/нечет, 1-10/11-20, точное число, буллсай.

Ничего дополнительно устанавливать не нужно: распознавание цифр — встроенный
Apple Vision, захват экрана — ScreenCaptureKit, голос — системный синтезатор.

Требуется macOS 14 (Sonoma) или новее.

## Скачать

**Вариант 1 — готовая сборка из GitHub Actions:**
откройте вкладку [Actions](../../actions) → последний зелёный запуск
«Build macOS app» → внизу страницы артефакт **DartsPredictor-macOS**
(внутри `DartsPredictor.dmg` и `DartsPredictor.app.zip`).

**Вариант 2 — собрать самому (одна команда):**

```bash
git clone <этот репозиторий>
cd xtr/DartsPredictorApp
./build_app.sh        # нужны Xcode Command Line Tools: xcode-select --install
open build
```

## Установка

1. Откройте `DartsPredictor.dmg` и перетащите **Darts Predictor** в «Программы»
   (или распакуйте `DartsPredictor.app.zip`).
2. Первый запуск: **правый клик по приложению → «Открыть» → «Открыть»**.
   Это нужно, потому что сборка не подписана сертификатом Apple Developer.
   Если macOS всё равно блокирует, выполните в Терминале:

```bash
xattr -cr /Applications/DartsPredictor.app
```

3. При первом старте наблюдения macOS попросит разрешение на **запись экрана**
   (Настройки → Конфиденциальность и безопасность → Запись экрана).
   Включите Darts Predictor и перезапустите приложение.

## Использование

1. Откройте трансляцию дартса так, чтобы счёт игроков (например, «276 - 354»)
   был виден и ничем не перекрывался.
2. В приложении нажмите **«Области счёта»**: экран затемнится — выделите мышью
   число счёта левого игрока, затем правого. Выделяйте плотно, только цифры.
   Настройка сохраняется, пока не передвинете окно браузера.
3. Нажмите **«Коэффициенты»** и впишите реальные коэффициенты из линии —
   от них зависит расчёт EV.
4. Нажмите **«Старт»**. После каждого броска:
   - большая плашка показывает лучшую ставку (зелёная — EV > 0, оранжевая — EV < 0);
   - в панели игрока — последние броски и топ-3 рекомендации;
   - голос произносит подсказку («Ставь от одиннадцати до двадцати»),
     отключается в настройках.

## Как это работает

Приложение ~7 раз в секунду снимает две крошечные области экрана со счётом.
Когда счёт стабильно изменился (два одинаковых чтения подряд — защита от
ошибок распознавания), разница считается броском. Броски копятся в модели
игрока: частоты секторов с экспоненциальным затуханием (свежие броски важнее)
и сглаживанием Лапласа. По модели считается вероятность каждого рынка и
EV = вероятность × коэффициент − 1; рекомендации сортируются по EV.

## Честное предупреждение

Броски — почти независимые события; программа ловит только тенденции игрока
(например, стабильную стрельбу в район 19–20). Букмекер закладывает маржу
в каждый коэффициент, поэтому на дистанции матожидание ставок, как правило,
отрицательное даже с идеальной статистикой. Если у рекомендации EV < 0 —
ставка математически убыточна. Это инструмент анализа, а не способ заработка.
