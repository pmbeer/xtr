# Личный отчёт Битрикс24

Сформируй отчёт через скрипт этого навыка, если пользователь просит аналитику своих действий в Битрикс24.

1. Определи период:
   - «прошлый месяц» → `--period last-month`;
   - «текущий месяц» → `--period this-month`;
   - «последние N дней» → `--period last-N-days`, добавив `--days N`;
   - точные даты → `--from YYYY-MM-DD --to YYYY-MM-DD`.
2. Запусти:

   ```bash
   node .cursor/skills/bitrix-personal-report/scripts/bitrix-report.mjs <аргументы периода>
   ```

3. Верни пользователю текст из stdout как готовый отчёт. Не изменяй цифры и не дополняй их предположениями.
4. Не показывай URL вебхука, токены, содержимое `.env` или необработанные ответы API.
5. Если скрипт завершился с ошибкой, сообщи безопасное описание ошибки и способ исправления. Для отсутствующего вебхука попроси создать `.env` из `.env.example` и заполнить `BITRIX_WEBHOOK_URL`.

Для произвольного периода используй включительные календарные границы. Если период не указан, уточни его у пользователя, а не выбирай сам.
