# Инструкция по печати ценников и этикеток

**Система:** 1С:Предприятие — «Управление нашей фирмой», редакция 3.0  
**Сеть:** ПивМастер  
**Раздел:** Продажи → Сервис → Печать этикеток и ценников

В сети магазинов ПивМастер используются **4 вида** ценников и этикеток:

| Вид | Когда использовать | Шаблон в 1С |
|---|---|---|
| Ценник на бутылочное пиво | Обычное бутылочное пиво | **Бутылочное пиво** |
| Акционный ценник | Уценка / акция (старая и новая цена) | **ПИВМАСТЕР АКЦИОННАЯ ЦЕНА** |
| Обычный ценник на штучный товар | Штучный товар без акции | **ПИВМАСТЕР ценник (New2)** |
| Этикетка на весовой товар | Весовой товар | **Этикетка вес. Термопринте** |

---

## 1. Открыть модуль печати

1. В левом меню откройте раздел **Продажи**.
2. В правой колонке в блоке **Сервис** выберите **Печать этикеток и ценников**.

Откроется окно **«Печать этикеток и ценников»**.

---

## 2. Проверить фильтры отбора (обязательно)

Перед подбором товара проверьте верхние поля.

### 2.1. Торговый объект

- Должен быть выбран **ваш склад / магазин**.
- Если поле пустое или указан неверный объект:
  1. Нажмите стрелку рядом с полем **Торговый объект**.
  2. Выберите **Показать все**.
  3. В окне **«Склады и магазины, Подразделения»** выделите нужный склад.
  4. Нажмите **Выбрать**.

### 2.2. Цены на дату

- Должна стоять **актуальная текущая дата**.
- Если дата неверная:
  1. Нажмите значок календаря у поля **Цены на дату**.
  2. Выберите **Сегодня**.

### 2.3. Вид цены

- В поле **Вид цены** укажите **Розничная цена** вашего магазина.
- Если значение не установлено:
  1. Стрелка → **Показать все**.
  2. Выберите **Розничная цена**.
  3. Нажмите **Выбрать**.

### 2.4. Вид цены акционный

- В поле **Вид цены акционный** должен быть выбран акционный вид цен на бутылочное пиво (например, **Акционная бут пиво**).
- Если не установлен — действуйте так же: стрелка → **Показать все** → выбрать нужный вид → **Выбрать**.

### 2.5. Печать на обычном принтере

- Обязательно должна стоять галочка **Печать на обычном принтере**.
- Без этой галочки 1С не сможет корректно распечатать ценник на обычном принтере.

> Поле **Каждая этикетка на новом листе** обычно оставляют без галочки.

---

## 3. Подобрать товар

Есть три способа добавить товар в таблицу для печати.

### Способ А. Сканер штрихкода (штучный товар)

1. Отсканируйте штрихкод товара сканером.
2. Товар автоматически добавится в подбор номенклатуры.

### Способ Б. Ввод штрихкода вручную

Если сканер не считывает код:

1. Нажмите значок **штрихкода с лупой**.
2. В окне **«Введите штрихкод»** введите код вручную.
3. Нажмите **OK**.
4. Товар добавится в таблицу.

### Способ В. Ручной подбор из номенклатуры

Если штрихкода нет или он нечитаемый (в т.ч. для весового товара):

1. Нажмите кнопку **Подобрать**.
2. В окне **«Подбор номенклатуры»** найдите товар:
   - через строку поиска, или
   - выберите из списка.
3. **Дважды щёлкните** левой кнопкой мыши по товару — он попадёт в **корзину**.
4. Нажмите **Перенести в документ** (перенести корзину в документ).
5. Товар появится в основной таблице печати.

---

## 4. Установить шаблон печати

1. Выделите нужную строку товара в таблице (галочка **Выбран**).
2. Нажмите **Установить** → **Шаблон печати**.
3. В окне **«Шаблоны этикеток и ценников БПО»** выберите шаблон по типу товара:

| Тип товара | Какой шаблон выбрать |
|---|---|
| Бутылочное пиво | **Бутылочное пиво** |
| Акционный / уценочный товар | **ПИВМАСТЕР АКЦИОННАЯ ЦЕНА** |
| Обычный штучный товар | **ПИВМАСТЕР ценник (New2)** |
| Весовой товар | **Этикетка вес. Термопринте** |

4. Нажмите **Выбрать**.
5. Название шаблона появится в колонке **Шаблон печати**.

---

## 5. Печать обычного ценника

1. Убедитесь, что выбран шаблон **ПИВМАСТЕР ценник (New2)** (или другой нужный неакционный).
2. Нажмите жёлтую кнопку **Печать**.
3. В окне предпросмотра проверьте:
   - название товара;
   - цену.
4. Если всё верно — ещё раз нажмите **Печать**.
5. Ценник распечатается на принтере.
6. Вырежьте ценник и вставьте в ценникодержатель у товара.

---

## 6. Печать акционного ценника

1. Через **Установить** → **Шаблон печати** выберите **ПИВМАСТЕР АКЦИОННАЯ ЦЕНА**.
2. Нажмите **Печать**.
3. В предпросмотре будут поля:
   - **Старая цена** (подставляется из системы, например 39 ₽);
   - **Новая цена** — её нужно заполнить вручную.
4. Чтобы указать новую цену (например, при уценке 18 ₽):
   1. **Дважды щёлкните** левой кнопкой мыши по полю новой цены.
   2. Впишите нужное значение.
   3. Щёлкните левой кнопкой мыши в любую пустую ячейку, чтобы зафиксировать ввод.
5. Нажмите **Печать**.
6. Акционный ценник распечатается на принтере.

---

## Краткая памятка

1. **Продажи** → **Печать этикеток и ценников**.
2. Проверить: **Торговый объект**, **дата = сегодня**, **Розничная цена**, **акционный вид цены**, галочка **Печать на обычном принтере**.
3. Добавить товар: сканер / ручной штрихкод / **Подобрать**.
4. **Установить** → **Шаблон печати** (по типу товара).
5. **Печать** → проверить данные → **Печать**.
6. Для акции: вручную вписать **новую цену** в предпросмотре, затем печатать.

---

## Частые ошибки

| Проблема | Что проверить |
|---|---|
| Ценник не печатается / ломается вёрстка | Галочка **Печать на обычном принтере** |
| Неверная цена | Поле **Цены на дату** = сегодня; верный **Вид цены** |
| Товар не находится | Правильный **Торговый объект**; поиск в **Подобрать** |
| На акционном ценнике пустая новая цена | Вписать вручную двойным кликом в предпросмотре |
| Не тот формат ценника | Заново выбрать шаблон через **Установить** → **Шаблон печати** |
