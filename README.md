# Bitrix24 Telegram Analytics

Telegram-бот формирует Excel-отчёт о личной активности в облачном Bitrix24:

- закрытые задачи за период;
- задачи, которые ещё не завершены, с разбивкой по статусам;
- обработанные обращения Открытых линий;
- среднее время между созданием и закрытием обращения.

## Подключение

1. В Bitrix24 создайте входящий вебхук с правами `task` и `imopenlines`. Скопируйте **полный** URL вида `https://portal.bitrix24.ru/rest/1/token/`.
2. Создайте бота через [@BotFather](https://t.me/BotFather) и сохраните токен.
3. Скопируйте `.env.example` в `.env` и заполните значения. `BITRIX24_USER_ID` — числовой ID сотрудника из Bitrix24. Чтобы бот отвечал только вам, задайте `TELEGRAM_ALLOWED_USER_ID`.
4. Установите зависимости и запустите:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e ".[dev]"
python -m bitrix_analytics
```

## Использование

В Telegram отправьте:

```text
/report
/report 2026-08-01 2026-08-12
```

Бот пришлёт `.xlsx`-файл. Первый запрос формирует отчёт с первого дня текущего месяца по сегодняшний день.

## Важные ограничения API

Данные доступны только в пределах прав вебхука. В некоторых тарифах Bitrix24 или конфигурациях Открытых линий REST-метод `imopenlines.session.list` недоступен — тогда отчёт не создастся до выдачи права/подключения соответствующего модуля. Метрика времени решения использует разницу `DATE_CREATE` и `DATE_CLOSE` сессии, поэтому не вычитает нерабочее время и не является SLA-метрикой.
