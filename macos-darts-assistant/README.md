# Darts Assistant для macOS

Нативный прототип захватывает выбранное окно через ScreenCaptureKit, локально
распознаёт историю результатов через Vision и после нового броска обновляет
подсказку. Целевая частота — 12 кадров/с, поэтому обработка обычно укладывается
в доли секунды и оставляет запас от пятисекундного окна.

## Важное ограничение

История не позволяет предсказать следующий результат честного независимого RNG.
Приложение ищет только устойчивое статистическое отклонение. Если данных мало или
доверительная граница не превышает базовую вероятность, оно показывает
`ПРОПУСТИТЬ`. Это намеренное поведение, а не ошибка.

Даже обнаруженное отклонение не гарантирует прибыль: для этого вероятность должна
быть выше вероятности безубыточности с учётом коэффициента и маржи букмекера.
Прототип не нажимает кнопки и не размещает ставки автоматически.

## Требования

- macOS 13 Ventura или новее;
- Xcode 15 или новее — только для сборки из исходников;
- разрешение **Запись экрана и системного аудио** для собранного приложения.

Все кадры анализируются на Mac и никуда не отправляются.

## Установка готового DMG

**Прямая ссылка (v1.1.0 Universal):**  
https://github.com/pmbeer/xtr/releases/download/darts-assistant-v1.1.0/DartsAssistant-1.1.0-macOS-universal.dmg

1. Скачайте DMG по ссылке выше (или артефакт из GitHub Actions).
2. Откройте `DartsAssistant-1.1.0-macOS-universal.dmg`.
3. Перетащите `DartsAssistant.app` в `Applications`.
4. При первом запуске подтвердите доступ к записи экрана.

Сборка ad-hoc подписана и не нотарифицирована Apple. Если Gatekeeper блокирует
первый запуск, нажмите правой кнопкой по приложению, выберите **Открыть**, затем
ещё раз **Открыть**. Для запуска обычным двойным щелчком без этого подтверждения
нужны сертификат Apple Developer ID и нотарификация.

## Запуск

1. Откройте `Package.swift` в Xcode.
2. Выберите схему `DartsAssistant` и **My Mac**, затем нажмите Run.
3. В приложении нажмите **Доступ к экрану…**, разрешите запись экрана и при
   необходимости перезапустите приложение.
4. Откройте игру, обновите список окон и выберите окно браузера.
5. Нажмите **Начать анализ**.
6. Ползунками X/Y/ширины/высоты оставьте в области OCR только историю последних
   бросков. Желательно видеть 5–20 ячеек, а не таймеры, баланс и счёт серии.
7. В блоке **Область игрока / ведущего** обведите человека на экране — Vision
   извлекает только координаты суставов, без сохранения изображения.
8. Проверьте строку **Числа**. Если новый результат находится в конце списка,
   отключите переключатель «Новейший результат распознаётся первым».

Окно помощника плавающее и остаётся поверх остальных окон. Голосовую подсказку
можно отключить.

## Как принимается решение

- OCR-снимок должен совпасть в двух последовательных кадрах.
- Сдвиг истории определяет новый бросок, включая два одинаковых результата подряд.
- Первое распознавание заполняет стартовую выборку.
- Рассматриваются числа 1–20, чёт/нечёт, диапазоны 1–10/11–20 и их пересечения.
- Используется beta-binomial сглаживание с априорной выборкой 20 бросков.
- До 30 наблюдений ставка всегда пропускается.
- Кандидат показывается только когда консервативная односторонняя граница с
  поправкой на одновременную проверку 28 вариантов выше базовой вероятности
  минимум на 3 процентных пункта.
- Параллельно работает online-модель: она предсказывает точный сектор 1–20,
  проверяет себя на следующем исходе и обновляет веса. Точность отображается
  в карточке **Online-обучение и поведение**; 99% не гарантируется.

## Проверка

На macOS:

```bash
cd macos-darts-assistant
swift test
swift run DartsAssistant
./build-installer.sh
```

Тесты покрывают минимальную выборку, равномерную историю, сильное смещение и
обнаружение сдвига истории, в том числе одинаковых результатов подряд.

## Ограничения прототипа

- Разметка страницы может измениться; тогда область OCR нужно настроить заново.
- Анимация, мелкий текст и перекрытие окна снижают качество OCR.
- Множители, промахи и bull сейчас не учитываются: модель принимает 1–20.
- Коэффициенты букмекера не считываются, поэтому подсказка означает обнаруженное
  отклонение, а не рассчитанную ожидаемую прибыль.
