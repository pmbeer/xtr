# Агент аналитики Битрикс24

Консольный агент, который через REST API облачного Битрикс24 собирает аналитику
вашей активности и формирует отчёт:

**Задачи**
- сколько задач закрыто за период;
- сколько задач сейчас в работе (с разбивкой по статусам: «Выполняется»,
  «Ждёт выполнения», «Ждёт контроля», «Отложена»);
- на каких стадиях канбана находятся задачи в проектах;
- сколько задач просрочено;
- среднее и медианное время выполнения задачи (от создания до закрытия).

**Открытые линии**
- сколько обращений обработано (закрытых сессий, где вы — оператор);
- среднее и медианное время решения вопроса;
- среднее время первого ответа;
- оценки клиентов (лайки/дизлайки, доля положительных);
- разбивка обращений по каналам (livechat, WhatsApp, Telegram и т.д.).

## Требования

- Python 3.9+
- Облачный Битрикс24 и права на создание входящего вебхука.
- Для блока открытых линий: обновление модуля `imopenlines 26.700.0`
  (раскатывается на порталы постепенно) и тариф с доступом к статистике
  Открытых линий (право `report_open_lines`). Если методы ещё недоступны,
  агент построит отчёт по задачам и явно сообщит, что блок открытых линий
  пропущен.

## Настройка

1. Создайте входящий вебхук на портале: **Разработчикам → Другое → Входящий
   вебхук**. Отметьте права доступа (scope):
   - **Задачи** (`task`);
   - **Открытые линии** (`imopenlines`);
   - **Пользователи** (`user`).
2. Скопируйте URL вебхука (вида `https://ваш-портал.bitrix24.ru/rest/1/токен/`).
3. Установите зависимости и задайте настройки:

```bash
cd bitrix24-agent
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# откройте .env и вставьте URL вебхука
```

Вебхук наследует права создавшего его пользователя, поэтому статистика видна
в пределах ваших прав на портале.

## Запуск

```bash
# отчёт за последние 30 дней (по владельцу вебхука)
python -m b24agent

# за неделю / сегодня / квартал / год
python -m b24agent --period week

# произвольный период
python -m b24agent --from 2026-07-01 --to 2026-07-31

# по другому сотруднику (нужны права на просмотр его задач и линий)
python -m b24agent --user-id 42

# JSON для интеграций/дашбордов (с --details добавит списки задач и сессий)
python -m b24agent --json --details --output report.json
```

## Регулярные отчёты

Проще всего запускать агента по расписанию через cron. Пример — отчёт каждый
понедельник в 9:00 за прошедшую неделю:

```cron
0 9 * * 1 cd /path/to/bitrix24-agent && .venv/bin/python -m b24agent --period week --output weekly-report.txt
```

## Какие методы REST используются

| Метод | Назначение |
|---|---|
| `profile`, `user.get` | Определение пользователя отчёта |
| `tasks.task.list` | Выборка задач (закрытые за период, в работе, созданные) |
| `task.stages.get` | Названия стадий канбана в проектах |
| `imopenlines.v2.Session.list` | Закрытые сессии открытых линий за период |
| `imopenlines.v2.Stat.get` | Сводные агрегаты по доступным линиям |

Агент учитывает лимиты облачного REST (~2 запроса/сек): выдерживает паузы
между вызовами и автоматически повторяет запросы при `QUERY_LIMIT_EXCEEDED`.

## Структура проекта

```
bitrix24-agent/
├── b24agent/
│   ├── cli.py        # командная строка
│   ├── client.py     # REST-клиент (вебхук, пагинация, ретраи, троттлинг)
│   ├── config.py     # настройки из окружения и .env
│   ├── tasks.py      # аналитика задач
│   ├── openlines.py  # аналитика открытых линий
│   ├── report.py     # текстовый и JSON-отчёт
│   └── util.py       # даты, периоды, форматирование
├── tests/            # юнит-тесты (без обращений к сети)
├── requirements.txt
└── .env.example
```
