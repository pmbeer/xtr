# Bitrix24 Analytics Agent

Агент для анализа вашей активности в облачном **Bitrix24**: задачи, открытые линии, KPI и средние времена ответа.

## Что умеет агент

### Задачи
- Сколько задач у вас в работе, ждут выполнения, ждут контроля
- Сколько задач закрыто за период
- Сколько задач создано за период
- Просроченные задачи
- Распределение по статусам, стадиям и проектам
- Среднее время выполнения закрытых задач

### Открытые линии
- Сколько обращений обработано
- Сколько сессий ещё открыто
- Среднее время первого ответа
- Среднее время решения вопроса
- Оценки клиентов (like/dislike)
- Разбивка по линиям и каналам

## Быстрый старт

### 1. Создайте входящий вебхук в Bitrix24

1. Откройте **Приложения → Разработчикам → Другое → Входящий вебхук**
2. Выдайте права:
   - `task` — задачи
   - `imopenlines` — открытые линии
   - `crm` — CRM (резервный источник данных по сессиям)
   - `user` — пользователи
3. Скопируйте URL вида:
   ```
   https://yourcompany.bitrix24.ru/rest/1/xxxxxxxxxxxxxxxx
   ```

### 2. Узнайте свой ID пользователя

В консоли Bitrix24 или через вебхук:
```
GET https://yourcompany.bitrix24.ru/rest/1/TOKEN/user.current
```

### 3. Настройте окружение

```bash
cd bitrix24-agent
cp .env.example .env
# Отредактируйте .env — укажите BITRIX24_WEBHOOK_URL и BITRIX24_USER_ID
pip install -r requirements.txt
```

### 4. Запустите агента

```bash
# Проверка подключения
python main.py --check

# Отчёт за текущий месяц
python main.py

# Отчёт за произвольный период
python main.py --from 2026-08-01 --to 2026-08-12

# Сохранить в JSON
python main.py --json report.json
```

## Использование как Cursor Cloud Agent

Агент можно запускать по расписанию через Cursor Automations или вручную в Cloud Agent:

1. Добавьте переменные окружения `BITRIX24_WEBHOOK_URL` и `BITRIX24_USER_ID` в настройки окружения
2. Установите зависимости: `pip install -r bitrix24-agent/requirements.txt`
3. Запускайте: `python bitrix24-agent/main.py --json /tmp/report.json`

## Ограничения Bitrix24 API

- **Открытые линии**: расширенная статистика (`imopenlines.v2.Session.Stat.get`) доступна на тарифах с модулем `report_open_lines`. На старых порталах агент использует fallback через `crm.activity.list`.
- **Лимиты REST API**: 2 запроса/сек (агент автоматически делает паузы между страницами).
- **Права вебхука**: данные видны только в рамках прав пользователя, от имени которого создан вебхук.
