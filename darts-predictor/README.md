# Darts Predictor для macOS

Программа следит за экраном во время трансляции дартса (например, «Игры 24/7»
на fon.bet), фиксирует каждый бросок по изменению счёта и **мгновенно**
(доли секунды, при окне ставки в 5 секунд) выводит в терминал и проговаривает
голосом рекомендацию по следующей ставке: чет/нечет, 1-10/11-20, конкретное
число или буллсай.

## Важно понимать (честное предупреждение)

- Броски дартсиста — почти независимые события. Программа умеет ловить только
  **тенденции игрока** (например, если он стабильно кладёт в район 19-20 —
  вырастут вероятности «нечет»/«11-20» и числа 19/20).
- Букмекер закладывает маржу в каждый коэффициент. Даже с идеальной
  статистикой матожидание ставок на дистанции, как правило, отрицательное.
  Программа показывает EV каждой рекомендации — если EV < 0, ставка
  математически убыточна. Это инструмент анализа, а не «кнопка деньги».

## Установка

1. Установите [Homebrew](https://brew.sh), затем Tesseract (движок распознавания цифр):

```bash
brew install tesseract
```

2. Установите зависимости Python (нужен Python 3.10+, на macOS: `brew install python`):

```bash
cd darts-predictor
python3 -m pip install -r requirements.txt
```

3. Разрешите терминалу запись экрана: **Системные настройки → Конфиденциальность
   и безопасность → Запись экрана** → включите Terminal (или iTerm). Без этого
   macOS будет отдавать чёрные скриншоты.

## Использование

1. Откройте трансляцию дартса в браузере так, чтобы счёт игроков
   (например, «276 - 354») был виден и не перекрывался другими окнами.

2. Откалибруйте области счёта (делается один раз, пока не поменяете
   расположение окна браузера):

```bash
python3 calibrate.py
```

   Откроется скриншот экрана. Мышью выделите число счёта левого игрока,
   нажмите Enter; затем то же для правого игрока. Выделяйте плотно —
   только цифры, без дефиса и имён.

3. Откройте `config.json` и впишите реальные коэффициенты из линии
   в секцию `"odds"` (чем точнее коэффициенты, тем честнее EV):

```json
"odds": {
  "even": 1.85,
  "odd": 1.85,
  "low": 1.85,
  "high": 1.85,
  "exact_number": 12.0,
  "bull": 15.0
}
```

4. Запустите наблюдатель:

```bash
python3 watcher.py
```

После каждого броска в терминале появится строка вида:

```
>>> [Левый игрок] бросок: 20  (счёт 276 -> 296, анализ 140 мс)
    история: [19, 20, 5, 20, 20]
    ЧЕТ: p=62%, кэф=1.85, EV=+0.15
    11-20: p=71%, кэф=1.85, EV=+0.31
```

и голос произнесёт лучшую рекомендацию («Ставь от одиннадцати до двадцати»).
Голос отключается в `config.json`: `"voice": false`.

## Как это работает

- `mss` снимает только две маленькие области экрана ~7 раз в секунду —
  это быстро и не грузит систему.
- Tesseract распознаёт числа счёта; значение принимается только после двух
  одинаковых чтений подряд, чтобы случайная ошибка OCR не считалась броском.
- Разница счёта = значение броска. Он добавляется в модель игрока
  (частоты секторов с экспоненциальным затуханием — свежие броски важнее,
  сглаживание по Лапласу — без нулевых вероятностей).
- По модели считается вероятность каждого рынка и EV при ваших коэффициентах;
  рекомендации сортируются по EV. Полный цикл «бросок → совет» занимает
  примерно 100–300 мс.

## Если что-то не так

- **Броски не детектятся** — перезапустите `calibrate.py` и выделите области
  точнее; проверьте разрешение на запись экрана.
- **Ложные броски / странные дельты** — программа сама пересинхронизируется
  и пишет об этом в лог; если часто — выделите области счёта плотнее.
- **Началась новая серия/матч** — счёт сбросится, программа это заметит и
  продолжит работу автоматически.
