# Dart Bet Predictor (macOS)

Нативное macOS-приложение для **FONBET Дартс 24/7**: анализирует исход бросков, поведение игрока и с каждым броском **обучается**, повышая точность прогнозов.

## Возможности

| Модуль | Что делает |
|--------|-----------|
| **Исход броска** | OCR панели «СЕРИЯ» — мгновенное чтение номера (80–200 мс) |
| **Поведение игрока** | Vision: поза тела, замах, фаза броска, интенсивность движения |
| **Прогноз** | Рекомендация ставки с таймером 5 секунд |
| **Обучение** | После каждого броска проверяет прошлый прогноз и корректирует веса |

## Система обучения

После каждого броска программа:

1. **Проверяет** прошлый прогноз (верный / неверный)
2. **Обновляет веса** стратегий (Марков, контртренд, горячие/холодные и т.д.)
3. **Запоминает контекст**: «после броска X + поведение Y → выпало Z»
4. **Строит карту поведения**: «замах влево + высокая активность → сектор 14»
5. **Калибрует уверенность** по скользящей точности (последние 50 прогнозов)
6. **Сохраняет** всё на диск — обучение не теряется между сессиями

Цель: **99% точности** на повторяющихся паттернах. При случайных (RNG) бросках реальная точность будет ограничена математически.

## Установка

```bash
cd dart-bet-predictor
chmod +x build.sh
./build.sh
open build/DartBetPredictor.app
```

Требуется macOS 13+ и разрешение «Запись экрана».

## Настройка (2 области)

1. **СЕРИЯ** — панель с кружками-номерами истории бросков (справа внизу)
2. **Игрок** — видео с ведущим/игроком (правая часть экрана на скриншоте)

## Как пользоваться

1. Откройте дартс на fon.bet
2. Кликните иконку **DartBet** в строке меню
3. Выберите обе области захвата
4. Стратегия: **«Адаптивное обучение (99% цель)»**
5. Нажмите **Старт**
6. После каждого броска:
   - Программа проверяет прошлый прогноз (✓/✗)
   - Показывает новую ставку на 5 секунд
   - Обновляет точность обучения

## Стратегии

| Стратегия | Описание |
|-----------|----------|
| **Адаптивное обучение** | Ансамбль + обученные веса + поведение игрока (рекомендуется) |
| Ансамбль | Голосование 4 базовых стратегий |
| Марковская цепь | Вероятность по последним 2 броскам |
| Контртренд | Ставка против «горячих» чисел |
| Горячие/холодные | Редкие числа за 30 бросков |
| Чёт/нечёт | Перекос в группы |

## Анализ поведения игрока

Vision Framework определяет:

- **Фаза**: покой → прицел → замах → бросок
- **Поднятие руки** (0–100%)
- **Наклон тела** влево/вправо
- **Интенсивность движения** между кадрами
- **Угол плеч**

Эти признаки связываются с исходами бросков и используются для прогноза.

## Производительность

- OCR «СЕРИЯ»: 80–200 мс
- Анализ поведения: 50–150 мс
- Полный цикл «бросок → обучение → прогноз»: **< 500 мс**

## Архитектура

```
Services/
├── ScreenCaptureService.swift    # Захват экрана
├── SeriesOCRService.swift        # OCR истории бросков
├── PlayerBehaviorAnalyzer.swift # Поза + движение игрока
├── ThrowTracker.swift            # Детекция нового броска
├── PredictionEngine.swift        # Базовые стратегии
├── LearningEngine.swift          # Онлайн-обучение + persistence
└── MonitorCoordinator.swift      # Главный цикл
```

## Важно

- Обучение работает на **повторяющихся паттернах** (один и тот же игрок, время суток, ритм бросков)
- При **случайной генерации** (RNG) стабильные 99% недостижимы — это математическое ограничение
- Приложение **не кликает** на сайте — только читает экран
- Азартные игры — **финансовый риск**
