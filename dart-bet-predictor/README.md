# Dart Bet Predictor (macOS)

Нативное macOS-приложение для анализа бросков в **FONBET Дартс 24/7** и мгновенной рекомендации ставки на следующий бросок.

## Что делает приложение

1. **Захватывает область экрана** — панель «СЕРИЯ» с историей бросков (справа внизу на скриншоте игры).
2. **OCR в реальном времени** — Apple Vision Framework читает номера (~80–200 мс на кадр).
3. **Детектирует новый бросок** — как только в «СЕРИИ» появляется новое число.
4. **Прогнозирует ставку** — ансамбль статистических стратегий.
5. **Показывает рекомендацию** — крупным шрифтом + таймер 5 секунд на ставку.

## Требования

- macOS 13 (Ventura) или новее
- Xcode 15+ или Swift 5.9+
- Разрешение «Запись экрана» в Настройки → Конфиденциальность

## Установка и запуск

```bash
cd dart-bet-predictor
chmod +x build.sh
./build.sh
open build/DartBetPredictor.app
```

Или через Swift Package Manager:

```bash
swift run DartBetPredictor
```

## Как пользоваться

1. Откройте игру **Дартс** на fon.bet в браузере.
2. Кликните иконку **DartBet** в строке меню (мишень).
3. Нажмите **«Выбрать область экрана»** и выделите панель **«СЕРИЯ»** с кружками-номерами.
4. Выберите стратегию (рекомендуется **«Ансамбль»**).
5. Нажмите **Старт**.
6. Откройте окно **«Прогноз ставки»** (появится рядом с иконкой в меню) и расположите его рядом с игрой.
7. После каждого броска приложение покажет:
   - **Число** (1–20) или
   - **ЧЕТ / НЕЧЕТ** или
   - **1–10 / 11–20** или
   - **Булл**
8. У вас **5 секунд** (настраивается) чтобы нажать нужную кнопку на сайте.

## Стратегии прогноза

| Стратегия | Описание |
|-----------|----------|
| **Ансамбль** | Голосование 4 стратегий, лучший консенсус |
| **Марковская цепь** | Вероятность следующего числа по последним 2 броскам |
| **Контртренд** | Ставка против «горячих» чисел последних 5 бросков |
| **Горячие/холодные** | Числа, которые редко выпадали в последних 30 бросках |
| **Чёт/нечёт** | Перекос в чётные, нечётные, 1–10 или 11–20 |

## Производительность

- OCR: **80–200 мс** (зависит от размера области и Mac)
- Частота опроса: **150 мс** по умолчанию (настраивается 80–400 мс)
- Полный цикл «бросок → рекомендация»: **< 500 мс** типично

## Важно

- Прогнозы **статистические** — если броски генерируются случайно (RNG), никакой алгоритм не даст стабильного преимущества.
- Приложение **не взаимодействует** с сайтом напрямую — только читает экран.
- Азартные игры несут **финансовый риск**. Используйте ответственно.

## Устранение проблем

| Проблема | Решение |
|----------|---------|
| Чёрный экран при захвате | Дайте разрешение «Запись экрана» и перезапустите приложение |
| OCR не читает цифры | Увеличьте область захвата, включите только «СЕРИЮ» |
| Медленный отклик | Уменьшите «Скорость OCR» до 80–100 мс |
| Ложные срабатывания | Убедитесь, что область не захватывает анимации |
