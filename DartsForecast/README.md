# Darts Forecast (macOS)

Нативное приложение для macOS: захват областей экрана букмекера, OCR результатов дартса, анализ поведения игрока и **ТОП-4** наиболее вероятных следующих чисел с онлайн-обучением.

Оптимизировано под **MacBook Pro 2018 / Intel / 8 GB RAM / macOS 15**.

> Приложение **не делает ставки** и не кликает по сайту. Режим по умолчанию — **Paper Prediction**.

## Быстрый старт

### Готовый установщик

1. GitHub → **Actions** → **Build Darts Forecast macOS**
2. Скачайте артефакт `DartsForecast-macOS-Installer` (`.dmg`)
3. Откройте DMG → перетащите **DartsForecast** в **Applications**
4. При первом запуске: ПКМ → «Открыть» (независимая подпись)

Подробнее: [INSTALL.md](INSTALL.md)

### Сборка на Mac

```bash
cd DartsForecast
./build-installer.sh
open dist/DartsForecast-2.0.0-macOS.dmg
```

## Первый запуск

1. Короткий онбординг
2. Разрешение «Запись экрана»
3. Область №1 — результат (числа серии)
4. Область №2 — игрок (видео)
5. Старт в режиме Paper Prediction

## Что показывает главный экран

- ТОП-4 чисел и нормализованные вероятности (сумма 100%)
- Уверенность: HIGH / MEDIUM / LOW (реальная, не завышенная)
- Последний результат, точность TOP-4, ✓/✗ прошлого прогноза
- Таймер окна решения (~5 сек)

Вкладки: **История**, **Обучение** (веса моделей, фазы), **Настройки**.

## Архитектура

См. [ARCHITECTURE.md](ARCHITECTURE.md).

Модули: ScreenCaptureManager → OCRManager → ThrowDetector → PlayerVisionAnalyzer → EnsemblePredictor (A–F) → LearningEngine → PredictionStore.

## Важно про точность

Проценты отражают **фактическую** историю прогнозов. Нет искусственного завышения до 99%. 99% — целевой ориентир обучения, не гарантия.
