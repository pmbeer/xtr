# Установка Darts Forecast

## Требования

- MacBook / Mac с **macOS 13+** (проверено на macOS 15.7.8)
- Intel x86_64 или Apple Silicon
- Разрешение **Запись экрана**

Рекомендуемая конфигурация: MacBook Pro 2018, 8 GB RAM.

## Установка из DMG (CI)

1. Откройте репозиторий на GitHub → вкладка **Actions**
2. Выберите workflow **Build Darts Forecast macOS**
3. Откройте последний успешный run
4. Скачайте **DartsForecast-macOS-Installer**
5. Распакуйте и откройте `DartsForecast-2.0.0-macOS.dmg`
6. Перетащите приложение в **Программы**
7. Первый запуск: правый клик → **Открыть** → подтвердите

Если macOS блокирует:

Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

## Разрешение записи экрана

Системные настройки → Конфиденциальность и безопасность → **Запись экрана** → включите **Darts Forecast**.

## Первый запуск

1. Прочитайте краткое объяснение
2. Разрешите захват экрана
3. Выделите **область результата** (числа последних бросков)
4. Выделите **область игрока** (видео)
5. Нажмите **Начать Paper Prediction**
6. Откройте трансляцию дартса у букмекера так, чтобы обе области были видны
7. После каждого подтверждённого результата смотрите ТОП-4 в главном / плавающем окне

## Сборка из исходников

```bash
git clone <repo>
cd DartsForecast
./build.sh          # только .app
./build-installer.sh # .app + .dmg
```

Артефакты:

- `build/DartsForecast.app`
- `dist/DartsForecast-2.0.0-macOS.dmg`

## Данные обучения

Сохраняются локально:

`~/Library/Application Support/DartsForecast/state.json`

Лог: `~/Library/Application Support/DartsForecast/debug.log`

Обучение **не сбрасывается** при закрытии приложения.

## Удаление

1. Удалите `DartsForecast.app` из Программ
2. (Опционально) удалите `~/Library/Application Support/DartsForecast`
