# StreamX — шаблон онлайн-кинотеатра для DataLife Engine

Современный тёмный шаблон в стиле **OKKO**, **IVI** и **Wink** для сайтов на CMS DataLife Engine.

## Возможности

- Hero-слайдер с рекомендуемым контентом на главной
- Горизонтальные карусели постеров (популярное, новинки, рейтинг)
- Страница фильма с плеером и метаданными
- Адаптивная вёрстка (десктоп, планшет, мобильные)
- Тёмная тема с фиолетово-розовым акцентом
- Формы входа, регистрации, комментариев
- Совместимость с DLE 13.x — 17.x

## Установка

### Способ 1: через ZIP-архив

1. Скачайте файл `dle_streamx.zip` из корня репозитория
2. Распакуйте архив
3. Загрузите папку `dle_streamx` на сервер в директорию `/templates/`
4. Войдите в админ-панель DLE: **Настройки → Система → Настройки сайта**
5. В поле **«Используемый шаблон»** выберите `dle_streamx`
6. Сохраните настройки и очистите кэш: **Инструменты → Очистка и оптимизация**

### Способ 2: вручную

1. Скопируйте папку `dle_streamx` в `/templates/` вашего сайта
2. Выберите шаблон в настройках DLE

## Настройка категорий

Создайте в DLE категории для контента:

| Категория   | Пример URL        |
|-------------|-------------------|
| Фильмы      | `/films/`         |
| Сериалы     | `/series/`        |
| Мультфильмы | `/cartoons/`      |

Меню категорий выводится автоматически через тег `{catmenu}`.

## Дополнительные поля (рекомендуется)

Для полноценной работы кинотеатра создайте дополнительные поля в DLE:

| Поле       | Тип    | Описание              |
|------------|--------|-----------------------|
| `year`     | Текст  | Год выпуска           |
| `genre`    | Текст  | Жанр                  |
| `country`  | Текст  | Страна                |
| `quality`  | Список | Качество (HD, 4K)     |
| `duration` | Текст  | Длительность          |
| `iframe`   | HTML   | Код видеоплеера       |

Вставьте код плеера в поле `iframe` или в полный текст новости — он отобразится в блоке плеера на странице фильма.

## Кастомные блоки на главной

Шаблон использует тег `{custom}` для вывода контента:

- `shortstory-hero` — слайды hero-баннера (5 случайных публикаций)
- `shortstory-poster` — постеры в каруселях (популярное, новинки, рейтинг)

Для вывода контента из конкретных категорий добавьте параметр `category`:

```
{custom category="1" template="shortstory-poster" limit="16" order="reads" cache="yes"}
```
