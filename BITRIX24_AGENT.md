# Агент отчётов Битрикс24 в Cursor

В репозитории есть project skill: `.cursor/skills/bitrix-personal-report`. Cursor Agent автоматически применяет его к запросам наподобие:

- «Сделай отчёт по моим задачам за прошлый месяц»;
- «Сколько обращений в Открытых линиях я обработал за последние 14 дней?»;
- «Дай отчёт с 2026-07-01 по 2026-07-31».

Для гарантированного запуска skill можно вызвать вручную: `/bitrix-personal-report`.

## Одноразовая настройка

1. В Битрикс24 откройте **Разработчикам → Другое → Входящий вебхук**.
2. Создайте вебхук от имени сотрудника, чьи показатели нужно анализировать.
3. Выдайте права: **Пользователь**, **Задачи**, а для показателей чатов — **Открытые линии**.
4. Создайте секретный файл:

   ```bash
   cp .env.example .env
   ```

5. Впишите в `.env` полный URL вебхука. Не добавляйте к нему название REST-метода.

   ```ini
   BITRIX_WEBHOOK_URL=https://ваш-портал.bitrix24.ru/rest/1/секретный_токен/
   ```

`.env` исключён из Git: не отправляйте URL вебхука в чат, коммиты или project rules.

## Что агент делает

Он запускает локальный скрипт, получает данные напрямую из Битрикс24 и возвращает готовый текстовый отчёт в чате Cursor. Скрипт рассчитывает:

- закрытые за период задачи;
- текущие активные и просроченные задачи и их статусы;
- обработанные и активные сессии Открытых линий;
- среднее время от создания до закрытия сессии.

Доступность показателей Открытых линий зависит от прав вебхука и тарифа/настройки портала. Для облачного Cursor секрет нужно добавить в переменные окружения cloud environment, а не коммитить в `.env`.
