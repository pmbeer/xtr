# Bitrix24 Telegram Analytics Bot

Telegram-бот на Python для анализа вашей активности в облачном Bitrix24. Формирует Excel-отчёты с задачами, статусами, обращениями в открытой линии и средним временем решения.

## Возможности

- **Задачи**: сколько закрыто, в работе, распределение по статусам и стадиям
- **Открытая линия**: количество обработанных обращений, среднее время решения и первого ответа
- **Excel-отчёт**: готовый файл с несколькими листами (сводка, задачи, открытая линия, статусы)
- **Гибкий период**: сегодня, неделя, месяц или произвольные даты

## Быстрый старт

### 1. Создайте Telegram-бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Сохраните полученный токен

### 2. Создайте входящий вебхук в Bitrix24

1. В Bitrix24: **Настройки → Разработчикам → Другое → Входящий вебхук**
2. Выберите права:
   - `task` — задачи
   - `imopenlines` — открытая линия
   - `user` — пользователи
   - `crm` — CRM (резервный источник для открытой линии)
3. Скопируйте URL вебхука (формат: `https://ваш-домен.bitrix24.ru/rest/1/ключ/`)

### 3. Узнайте ваш ID в Bitrix24

В профиле пользователя или через вебхук:
```
GET https://ваш-домен.bitrix24.ru/rest/1/ключ/user.current
```

### 4. Установка и запуск

```bash
cd bitrix_telegram_bot
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# Заполните .env своими значениями
python -m bot.main
```

### 5. Настройка `.env`

```env
TELEGRAM_BOT_TOKEN=123456:ABC...
BITRIX_WEBHOOK_URL=https://your.bitrix24.ru/rest/1/your_key/
BITRIX_USER_ID=1
ALLOWED_TELEGRAM_IDS=123456789
```

`ALLOWED_TELEGRAM_IDS` — список Telegram ID пользователей с доступом (через запятую). Если пусто, доступ открыт для всех.

## Использование в Telegram

| Команда / запрос | Действие |
|------------------|----------|
| `/start` | Помощь |
| `/report` | Excel-отчёт за 30 дней |
| `/report сегодня` | Отчёт за сегодня |
| `/report неделя` | Отчёт за 7 дней |
| `/report 2024-01-01 2024-01-31` | Отчёт за период |
| `/summary` | Краткая сводка без файла |
| `отчёт месяц` | Текстовый запрос с периодом |

## Структура Excel-отчёта

1. **Сводка** — ключевые метрики
2. **Задачи** — список всех задач с деталями
3. **Открытая линия** — список обращений
4. **Статусы задач** — разбивка по статусам и стадиям

## Требования Bitrix24

- Облачный Bitrix24 с REST API
- Входящий вебхук с правами на задачи и открытую линию
- Для статистики открытой линии может требоваться право `report_open_lines` (зависит от тарифа)

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| `403 B24_TARIFF_RESTRICTION` | Тариф не включает статистику открытой линии |
| Пустой список сессий | Проверьте `BITRIX_USER_ID` и права вебхука |
| `Unauthorized` в Telegram | Проверьте `TELEGRAM_BOT_TOKEN` |
| Нет доступа к боту | Добавьте ваш Telegram ID в `ALLOWED_TELEGRAM_IDS` |
