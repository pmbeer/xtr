# StreamX — шаблон онлайн-кинотеатра для DLE

Готовый шаблон в стиле популярных онлайн-кинотеатров (Okko, IVI, Wink): тёмный cinematic UI, hero-слайдер, горизонтальные полки с постерами, страница фильма с плеером.

Совместимость: DataLife Engine 14.x–19.x (стандартные теги шаблонов).

## Установка

1. Распакуйте архив.
2. Загрузите папку `streamx` на хостинг в каталог:
   `/templates/streamx/`
3. В админпанели DLE:
   **Настройки скрипта → Общие настройки / Оформление → Шаблон сайта** → выберите `streamx`.
4. Очистите кеш шаблонов (если включён).

## Категории на главной

В `main.tpl` блоки `{custom category="1"}` и `{custom category="2"}` — это ID категорий:

| Блок на главной | ID по умолчанию | Что поставить |
|-----------------|-----------------|---------------|
| Фильмы          | 1               | ID вашей категории «Фильмы» |
| Сериалы         | 2               | ID вашей категории «Сериалы» |

ID смотрите в админке: **Категории**.

Рекомендуемые ЧПУ категорий (как в меню шаблона):

- `/films/` — Фильмы
- `/series/` — Сериалы
- `/cartoons/` — Мультфильмы
- `/top/` — Топ (по желанию)

## Дополнительные поля (xfields)

Создайте в админке (**Дополнительные поля новостей**) поля с именами:

| Имя поля   | Тип        | Назначение                          |
|------------|------------|-------------------------------------|
| poster     | Изображение / строка | Постер                        |
| backdrop   | Изображение / строка | Фон для hero/страницы фильма  |
| year       | Строка     | Год                                 |
| genre      | Строка     | Жанры                               |
| country    | Строка     | Страна                              |
| director   | Строка     | Режиссёр                            |
| actors     | Строка     | Актёры                              |
| time       | Строка     | Длительность (минуты)               |
| quality    | Строка     | HD / FullHD / 4K                    |
| age        | Строка     | 0+ / 6+ / 12+ / 16+ / 18+           |
| kp         | Строка     | Рейтинг Кинопоиска                  |
| imdb       | Строка     | Рейтинг IMDb                        |
| slogan     | Строка     | Короткий слоган                     |
| trailer    | Строка     | Ссылка на трейлер                   |
| player     | Текст      | HTML/iframe плеера                  |

Если `poster` пустой, шаблон возьмёт первую картинку из новости `{image-1}`.

## Советы по контенту

- В краткую новость — короткое описание.
- В полную — развёрнутое описание.
- В поле `player` вставьте iframe/код плеера.
- Для hero загружайте широкие `backdrop` (примерно 1920×800).
- Для карточек — вертикальные постеры (2:3).

## Кастомизация

Цвета и шрифты — в `css/styles.css` (`:root`).
Скрипты слайдера и полок — `js/app.js`.
Бренд «StreamX» можно заменить поиском по файлам шаблона.
