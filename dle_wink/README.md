# Wink — полная копия дизайна wink.ru для DLE

Шаблон максимально точно воспроизводит визуальный дизайн и UX **wink.ru** для CMS DataLife Engine.

## Что включено (1:1 с wink.ru)

### Страницы и разделы
| Раздел | Шаблон | Как на Wink |
|--------|--------|-------------|
| Главная | `main.tpl` | Hero-слайдер, промо-полоса, карусели |
| Фильмы | `fullstory.tpl` | Плеер, рейтинги, актёры, «О фильме» |
| Сериалы | `fullstory-series.tpl` | Сезоны, серии, эпизоды |
| ТВ-каналы | `tv.tpl` | Список каналов с EPG |
| Спорт | `sport.tpl` | Спортивные трансляции |
| Детям | `kids.tpl` | Детский каталог |
| Подписки | `services.tpl` | Тарифные планы |
| Поиск | `search.tpl` | Результаты + рекомендации |
| Авторизация | `registration.tpl` | Вход по телефону +7 |
| Профиль | `userinfo.tpl` | Личный кабинет |

### Компоненты
- Промо-полоса «7 дней бесплатно»
- Header с полным меню Wink (11+ пунктов)
- «Продолжить просмотр» (для авторизованных)
- Карусели: Новинки, Выбор зрителей, СТС/ТНТ, Wink Originals
- Видеоплеер с настройками (качество, скорость, пропорции)
- Модалка «Поделиться»
- Footer с соцсетями и магазинами приложений

### Дизайн-система
- Цвета: `#FF5A24` (оранжевый), `#0E0C0E` (фон), `#D331DB` (промо)
- Шрифты: CoFo Sans / CoFo Kak (с block.wink.ru)
- Pill-кнопки, белая «таблетка» в навигации
- Постеры 158×230 (2:3), карточки continue 16:9

## Установка

```
1. Загрузите папку dle_wink в /templates/
2. Админка DLE → Настройки → Шаблон: dle_wink
3. Создайте статические страницы: tv, sport, kids, services, faq, offer
4. Создайте категории: movies, series, originals, kids
5. Настройте доп. поля (см. ниже)
6. Очистите кэш
```

## Дополнительные поля DLE

| Поле | Тип | Для чего |
|------|-----|----------|
| `duration` | Текст | Длительность |
| `age` | Текст | Возраст (6+, 18+) |
| `country` | Текст | Страна |
| `quality` | Список | HD, 4K |
| `kinopoisk` | Текст | Рейтинг КП |
| `imdb` | Текст | Рейтинг IMDb |
| `trailer` | Текст | URL трейлера |
| `seasons` | Текст | Кол-во сезонов |
| `season` | Текст | Номер сезона |
| `episode` | Текст | Номер серии |
| `cast` | HTML | Актёры |
| `iframe` | HTML | Код плеера |

## Превью без DLE

Откройте `dle_wink/preview/index.html` в браузере.

## Что требует дополнительной настройки

Шаблон — это **визуальная и UX-копия**. Для полного функционала Wink на вашем сайте:

| Функция Wink | Что нужно |
|--------------|-----------|
| Оплата подписок | Модуль оплаты (Robokassa, ЮKassa) |
| SMS-авторизация | SMS-шлюз + кастомный модуль |
| ТВ-эфир | IPTV-потоки + плеер (HLS) |
| Рекомендации | Настройка `{custom}` блоков / ML-модуль |
| Скачивание | Мобильное приложение или PWA |
