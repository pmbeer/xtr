# Bitrix24 Analytics Bot — Telegram-бот аналитики вашей работы в Bitrix24

Бот на Python, который подключается к облачному Bitrix24 через REST (входящий вебхук),
анализирует вашу активность и по запросу присылает готовый Excel-файл с результатами.

## Что умеет

- **Задачи**: сколько задач закрыто за период, сколько сейчас в работе,
  сколько просрочено, на каких стадиях (канбан-стадии групп или статусы) находятся открытые задачи.
- **Открытые линии**: сколько обращений вы обработали за период, сколько ещё открыто.
- **Скорость работы**: среднее время выполнения задачи и среднее время решения обращения.
- **Запросы на естественном языке**: боту можно писать обычным текстом —
  «сколько задач я закрыл за неделю?», «отчёт за прошлый месяц», «среднее время решения вопроса за квартал».
- **Отчёт файлом**: на каждый запрос бот присылает краткую сводку в чат и
  подробный файл `.xlsx` с листами «Сводка», «Закрытые задачи», «Задачи в работе», «Обращения».

## Требования

- Python 3.11+
- Облачный Bitrix24 с правами на создание входящего вебхука
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather)

## Настройка Bitrix24

1. В Bitrix24 откройте **Разработчикам → Другое → Входящий вебхук**.
2. Выдайте вебхуку права доступа:
   - `task` (Задачи),
   - `crm` (CRM — используется для статистики открытых линий),
   - `imopenlines` (Открытые линии),
   - `user` (Пользователи).
3. Скопируйте URL вебхука вида `https://ваш-портал.bitrix24.ru/rest/1/abc123def456/`.
4. Узнайте свой ID пользователя (виден в адресной строке на странице вашего профиля:
   `/company/personal/user/<ID>/`).

> Статистика открытых линий считается по делам CRM с провайдером
> `IMOPENLINES_SESSION`. Для этого открытая линия должна быть подключена к CRM
> (стандартная настройка «Регистрировать обращение в CRM» в настройках линии).

## Установка и запуск

```bash
cd bitrix24_telegram_bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# заполните .env своими значениями

python bot.py
```

### Переменные окружения (`.env`)

| Переменная | Описание |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather |
| `BITRIX_WEBHOOK_URL` | URL входящего вебхука Bitrix24 |
| `BITRIX_USER_ID` | ID пользователя Bitrix24, по которому считается статистика |
| `ALLOWED_TELEGRAM_IDS` | Telegram ID, которым разрешён доступ (через запятую); пусто — доступ всем |
| `TIMEZONE` | Часовой пояс портала, по умолчанию `Europe/Moscow` |

## Примеры запросов боту

- `/report` — полный отчёт за текущий месяц
- `/today`, `/week` — отчёт за сегодня / текущую неделю
- «сколько задач я закрыл вчера?»
- «какие задачи у меня в работе и на каких стадиях?»
- «сколько обращений я обработал за прошлую неделю?»
- «среднее время решения вопроса за квартал»
- «полный отчёт за год»

Бот понимает периоды: *сегодня, вчера, неделя, прошлая неделя, месяц,
прошлый месяц, квартал, год*. Если период не указан — берётся текущий месяц.

## Структура проекта

```
bitrix24_telegram_bot/
├── bot.py                # точка входа: Telegram-бот (aiogram 3)
├── config.py             # загрузка конфигурации из .env
├── nlp.py                # разбор запросов на русском (период + метрики)
├── bitrix/
│   └── client.py         # REST-клиент Bitrix24 с пагинацией и ретраями
├── analytics/
│   ├── periods.py        # вычисление границ периодов
│   ├── tasks.py          # статистика по задачам
│   └── openlines.py      # статистика по обращениям открытых линий
└── reports/
    └── excel.py          # генерация xlsx-отчёта
```

## Запуск как сервис (systemd)

```ini
# /etc/systemd/system/bitrix24-bot.service
[Unit]
Description=Bitrix24 Analytics Telegram Bot
After=network.target

[Service]
WorkingDirectory=/opt/bitrix24_telegram_bot
ExecStart=/opt/bitrix24_telegram_bot/.venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now bitrix24-bot
```
